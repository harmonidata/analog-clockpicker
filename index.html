Fitur Clock Picker:

  • Klik & Drag jarum jam secara bebas dengan mouse atau jari di HP.
  • Auto-Advance otomatis beralih ke pemilihan menit setelah jam dipilih.
  • Dual Mode 12H / 24H (AM/PM atau mode 24 jam dengan ring konsentris).
  • Audio Feedback suara detik mekanik menggunakan Web Audio API.
  • 100% Vanilla JS + Tailwind CSS tanpa library eksternal yang berat.
